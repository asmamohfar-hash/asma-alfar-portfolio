# Asma Al-far — AI & Technology Portfolio

A bilingual Arabic/English personal portfolio for Asma Mohammad Al-far, a computer engineer and AI explorer from Irbid, Jordan.

## Highlights

- Dark editorial visual system with electric violet, warm saffron, and midnight navy.
- Responsive portfolio layout for desktop and mobile.
- CV-led sections for experience, education, skills, certifications, languages, and contact details.
- Dedicated AI course showcase with original generated visual assets.
- Smooth anchor navigation and reduced-motion support.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm check
pnpm build
```
